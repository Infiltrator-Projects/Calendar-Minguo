# Republic of China Minguo Calendar

Minguo calendar era and local formatting remain with the provider. Common 1.19.80 (dc4aac326964ca4400b6e21851d16eea674040c8) supplies neutral arithmetic, JDN/Gregorian coordinates, shared public ABI and validation. Provider builds the actual Common archive from a pinned submodule, eliminating local duplicate Common files. Source ZIP, native offline installer and model fixtures are retained.
